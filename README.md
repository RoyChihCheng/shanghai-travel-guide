# 上海五天四夜極致自由行詳細攻略與互動指南 (Shanghai 5D4N Field Travel Guide)

專為上海 5 天 4 夜深度自由行打造的互動式旅行指南網頁與高解析離線 PDF 手冊。整合外灘與陸家嘴雙面天際線、梧桐法租界慢調散步、文博藝術與抗戰歷史記憶、朱家角水鄉古鎮、30 大必去景點與 30 種必吃本幫名點全圖鑑。

## 🌟 核心特色與實地導航亮點
- **5 大維度實景路標無死角認路系統**：
  1. 🚇 **地鐵線路與車站官方色彩速查**：涵蓋 1、2、4、7、8、9、10、11、12、13、14、17 號線官方配色代碼、精確出站閘口編號。
  2. 🚪 **站內地下通道跟隨指標**：對照現場指示牌精確文字（如「南京路步行街/西藏中路」、「福佑路/豫園」、「安福路/話劇藝術中心」）。
  3. 🪧 **上海街道路牌雙向解碼**：現場實證「**東西走向深藍底白字**」（如 `[ 淮海中路 HUAIHAI RD.(M) ]`、`[ 南京東路 EAST NANJING RD. ]`）與「**南北走向深綠底白字**」（如 `[ 武康路 WUKANG RD. ]`、`[ 四川中路 SICHUAN RD.(M) ]`），抬頭即知方向。
  4. 🏬 **官方門牌實址與店鋪名稱**：精確至區、路、號、弄堂門牌。
  5. 🧭 **肉眼轉彎地標識別**：包含天平路安全島最佳武康大樓機位、乍浦路橋東方明珠同框機位、東金線渡輪二層甲板等。
- **首選名店 ✕ 超強應急備案機制**：每餐與下午茶皆配置同區域頂尖備案，遭遇排長隊或公休可無縫切換，保證旅程節奏不受影響。
- **2026 最新官方資訊核實**：
  - 更新**上海博物館東館 (世紀大道)** 展覽現況，匯集古代青銅、陶瓷、書畫國寶大館。
  - 新增**浦東美術館 (MAP)** 讓·努維爾建築傑作與「鏡廳」夕陽絕景機位。
  - 新增外灘 2 元平價渡輪「**東金線輪渡**」（金陵東路渡口 ➔ 東昌路渡口）橫渡黃浦江全攻略。
  - 核實老字號現況（富春小籠愚園路舊址因舊改搬遷之替代方案與分店指引）。
- **四大老字號必買伴手禮專題**：國際飯店蝴蝶酥（附免排隊攻略）、沈大成條頭糕/雙釀團、泰康食品鮮肉月餅與泰康黃牌辣醬油、光明邨醬鴨與現煎月餅。
- **極速返程與機場連線**：完整收錄地鐵直達與龍陽路搭乘「**上海磁浮列車**」（持機票 40 元、7 分鐘飆速抵達浦東機場）實戰教學。
